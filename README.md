# Sarosh Alam Ghausi — Academic Website

A responsive, publication-focused academic website for GitHub Pages. Built with plain HTML, CSS, and JavaScript; no build tools or paid hosting required.

## Publish using GitHub Pages

1. Sign in to GitHub and create a **public** repository named `sarosh-alam-ghausi.github.io` (replace `sarosh-alam-ghausi` with your exact GitHub username).
2. Upload all files in this folder to the repository root. Keep `index.html`, `styles.css`, and `script.js` together.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for the Pages deployment to finish. Your site should be available at `https://YOUR-USERNAME.github.io/`.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Before you announce the site

- Replace the Google Scholar link in `index.html` with your actual profile URL.
- Check your biography, current title, research themes, publication metadata, and contact details.
- Add a professional photograph if you want one. Save it under `assets/` and update the hero section in `index.html`.
- Add any further publications, students, collaborators, CV, or teaching details you want public.
- Test on mobile and desktop.
- Keep your Google Sites page online until the new site is checked and you have updated links from your institutional profile.

## Editing content

- `index.html`: page content and publication list.
- `styles.css`: colours, layout, typography, responsive behaviour.
- `script.js`: mobile menu and publication search.

The website uses Google Fonts and an external link to your IIT Kanpur profile. The rest is static and hosted by GitHub Pages.
